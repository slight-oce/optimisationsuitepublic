# Slightly Optimised

PC optimisation for Windows gaming machines. The Slightly Optimised app is not publicly available yet - follow
[slightlyoptimised.gg](https://slightlyoptimised.gg) for the release.

## Free downloads

- **[MW4 settings script](MW4/)** - one script that sets Call of Duty: Modern Warfare 4 to our competitive settings
  on any PC. It keeps your own monitor, audio and controls, backs up first, and undoes with one command.
